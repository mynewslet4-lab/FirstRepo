# Summary of Files

This document provides a summary of the files in the repository.

## `calc_actions.py`

This file contains a set of functions for performing basic arithmetic operations.

- `add(a, b)`: Adds two numbers.
- `subtract(a, b)`: Subtracts one number from another.
- `multiply(a, b)`: Multiplies two numbers.
- `divide(a, b)`: Divides one number by another, with a check for division by zero.
- `power(a, b)`: Raises a number to the power of another.
- `modulo(a, b)`: Calculates the remainder of a division.

## `first.py`

This file contains a single line of Python code that prints the string "hi" to the console.
